⚡ Features

Everything you need to audit your databases

From real-time event streaming to row-level diffs and configurable alert rules.

⚡
Live Event Stream
Socket.IO-powered real-time feed of every INSERT, UPDATE, DELETE, and DDL change. Capped at 200 events with instant clear.
🔍
Row-level Diff Viewer
Every UPDATE exposes a before/after JSON diff with highlighted changed columns — like git diff but for your database rows.
📊
Statistics Panel
Operations donut chart, top tables bar, and top actors bar. Instant snapshot of what's happening across your connection.
🔔
Alert Rules Engine
Full CRUD alert rules with a condition builder. Trigger on TRUNCATE, bulk DELETE, schema changes, or unauthorized access.
🌐
Multi-DB Support
PostgreSQL, MySQL, MSSQL, MongoDB, SQLite, and Redis — all in one unified connection tree sidebar.
🔐
JWT Auth
Secure login with token persistence in localStorage. Every API call and WebSocket handshake auto-attaches the Bearer token.
🔍 Diff Viewer

See exactly what changed

Every UPDATE event captures the full before and after state. Click any row in the live feed to instantly see a highlighted column diff — no query logs, no guesswork.
